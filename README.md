# Cloud Security Misconfigurations

## Project Overview
This project explores common cloud security misconfigurations, their potential risks, prevention methods, and safe verification steps.

## Key Areas Covered
- Overly Broad IAM Permissions
- Public Storage Access
- Exposed Secrets
- Missing Security Logging
- Insecure Network Rules

## Project Files
- `Cloud_Security_Technical_Report_Janvi_Pandey.docx` – Detailed technical report.
- `Cloud_Security_Risk_Table.docx` – Risk assessment table with impact, prevention, and verification steps.

## Objective
To understand common cloud security risks and learn how to prevent and safely identify them using sample configurations.

## Verification
This project uses research and sample-based verification. No live cloud resources were tested or modified.
